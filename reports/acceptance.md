# Alinea v0.2-mvp 最终验收报告

## 结论

**本地 MVP 业务闭环验收通过。** 上传 → 规则确认 → 检查 → PDF 高亮 → 选择性审批修复 → G1–G5 复检 → DOCX/PDF/JSON/Markdown 下载与审计均已在真实文件和真实浏览器中完成。

这不等于生产发布验收完成：Docker/镜像、公网部署、全量 mypy、人工 Microsoft Word 视觉核验和 30 页 P95 性能测试仍未完成。以下所有数字来自实际执行，不把 PRD 目标写成实测结果。

## 规范与模型抽取

- 中文自然语言直接实测：6 条原子规则，14.094 秒，0 次结构重试，来源校验通过。
- 文本 PDF 直接实测：32 条规则，119.079 秒；输入 1,476 tokens、输出 6,822 tokens，0 次结构重试。
- API 复核：PDF 规则 32 条，页码与原句绑定正确；自然语言规则 3 条，来源原句完整。
- 原 60 秒模型超时配置会拒绝长 PDF，已根据真实耗时调整为 180 秒；结构、来源和人工批准要求未放宽。
- Agents SDK 外部 tracing 禁用，模型无文件写入或 Shell 工具。密钥只通过进程环境传入，源码/测试/报告扫描未发现真实密钥。

## 未完成与限制

1. **类型治理**：全量 mypy 初次报告 170 项动态 JSON/Pydantic 类型边界问题。Ruff、pytest、vue-tsc 和生产构建通过，但不能声称全量 Python 类型检查通过。实际 RQ `Connection` 兼容问题已修复为显式连接注入。
2. **容器与发布**：本机无 Docker，未构建 Compose、未记录镜像 digest、未做公网部署。配置存在不等于容器验收通过。
3. **性能**：没有 30 页文档的 P95 数据，也没有生产并发压测。冷转换、缓存和 E2E 时间不可互相替代。
4. **视觉与兼容性**：未进行人工 Microsoft Word 视觉核验；复杂 OOXML、缺失字体、复杂阅读顺序和 Word/LibreOffice 分页差异仍需按支持矩阵降级。
5. **许可**：SBOM 已生成，但不是法律审查。未打包受限字体；生产发布仍需镜像/字体/传递依赖许可复核。
6. **覆盖边界**：指标仅适用于合成/脱敏样本和已实现规则，不能宣称任意论文或复杂 DOCX 均具有相同准确率。
